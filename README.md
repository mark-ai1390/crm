## Запуск

Node.js >=22, без npm-зависимостей.

```bash
./init.sh
npm run dev
```

Открыть http://localhost:5173. `npm run check`, `npm test`, `npm run build` выполняются отдельно. Сборка в dist/. В managed Sites запуск preview допустим только с поддерживаемым control-browser.

## Сценарий

Откройте заказ #1048, подтвердите состав, внесите остаток оплаты и отгрузите. Остатки товара, история и аналитика изменятся вместе. Создание нового заказа запускает локальное правило задачи, если оно включено. В профиле можно переключать демонстрационные роли. В настройках доступны экспорт JSON, проверяемый импорт, сброс и перенос данных прежней CRM.

Данные сохраняются в localStorage (`4sales:crm:v2`). Фиксированная демонстрационная дата — 12 октября 2026. Настоящие сообщения, платежи и интеграции не подключены. Прежний интерфейс доступен в `/legacy/index.html`; ключ v1 не удаляется.

Код v2: public/assets/v2/. Снимок данных и Figma ID: docs/design/. Для нового дизайна используются точные SVG из его компонентов и локальный Inter. Личные фотографии не входят в публичную поставку; аватары — инициалы.

34 автоматические проверки проходят. Браузерная/визуальная приёмка веб-версии остаётся `needs_verification`: control-browser в рабочей среде недоступен. См. матрицу в docs/04-verification.md.

Исходный crm-implementation-plan.md сохранён как исторический план от 4 октября: на тот момент макеты и план существовали, код нового сайта ещё не был создан. Актуальный статус — claude-progress.md.
