# 4sales CRM
Демонстрационная CRM Марка Сангинова для портфолио. Новый проект на основе макетов CRMED; начало работы — 4 октября 2026.

## Запуск
Нужен Node.js 22 или новее. В проекте нет сторонних runtime-зависимостей.

```sh
./init.sh
npm run dev
```

Откройте http://localhost:5173. Для проверки и подготовки статики:
```sh
npm run check
npm test
npm run build
npm run preview
```

Исходники сайта находятся в public/, результат сборки — dist/. Порт сервера можно изменить: PORT=3000 npm run dev.

## Статус
Макеты и план подготовлены. Реализована главная страница по новому дашборду: KPI, выручка, каналы, показатели команды, выбор месяца и периода, CSV, панели уведомлений/профиля/демо-разбора и два уровня сайдбара. На исходной точке настройки код нового сайта отсутствовал. Актуальный статус и результаты проверок — в [claude-progress.md](claude-progress.md); очередь задач — в [feature_list.json](feature_list.json).

Остальные семь макетов и полноценная браузерная сверка ещё в очереди. При сборке dashboard.html создаётся из того же index.html, без второй независимой копии.

Данные и операции CRM демонстрационные. Полноценный сервер и внешние интеграции входят в отдельный объём.


В публичном репозитории аватар показан инициалами МС. Приватный Site использует исходную фотографию Figma; её публикация в GitHub ожидает явного разрешения автора.
