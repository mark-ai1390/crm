## Ограничения, которые остаются

1. **Браузерная приёмка не выполнена.** В managed-среде отсутствует control-browser. Согласно Sites preview-сервер и альтернативный browser-control не запускались. Проверки рендера строк HTML не заменяют DOM, клики, раскладку, клавиатуру и консоль.
2. Не выполнено пользовательское тестирование. Ни скорость обработки, ни конверсия, ни бизнес-результаты не измерялись.
3. Code Connect недоступен: Figma сообщил о необходимости Dev/Full seat на Organization/Enterprise. Соответствия компонентов задокументированы в docs/design/component-map.md; опубликованной Code Connect-интеграции нет.
4. Данные локальны для браузера. Многопользовательская синхронизация, серверная авторизация, настоящие платежи, SMS, email и доставка не входят в эту демонстрационную версию.
5. Несохранённые изменения защищены подтверждением выхода; используется нативное окно браузера. Тестировать на реальных браузерах отдельно.
